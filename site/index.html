Install

Clone the repo and link a skill into your agent's skills folder:

git clone https://github.com/Taanviir/skills.git && cd skills
ln -s "$PWD/skills/graphite-ui" ~/.claude/skills/graphite-ui   # Claude Code
ln -s "$PWD/skills/graphite-ui" ~/.agents/skills/graphite-ui   # Codex

Then ask for the task in plain words. The agent loads the matching skill.
