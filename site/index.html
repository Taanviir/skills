Taanviir's skills

Skills I use day to day with Claude Code and Codex. Each one teaches the agent one job. Each is also tested end to end: the agent does the task in a fresh folder, and evals check what it built.

Skills

graphite-ui

A design system as a skill. Reworks an app's UI onto Graphite UI tokens and component recipes, then runs an audit that proves nothing hardcoded is left.

See the boardSource

project-presentation

Turns a repository into one self-contained HTML slide deck for stakeholders, using the repo's own content and brand colors.

Source

create-info-cards

Turns a YouTube video, article or PDF into 1080×1350 image cards on a collage page. Each card exports as a PNG.

Source

Install

Clone the repo and link a skill into your agent's skills folder, then ask for the task in plain words.

git clone https://github.com/Taanviir/skills.git && cd skills
ln -s "$PWD/skills/graphite-ui" ~/.claude/skills/graphite-ui   # Claude Code
ln -s "$PWD/skills/graphite-ui" ~/.agents/skills/graphite-ui   # Codex
