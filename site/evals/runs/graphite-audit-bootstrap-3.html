Bootstrap compiles those colors in with Sass, which is why the !important hack exists. - Bootstrap color utilities in the markup: these read --bs-*-rgb triplets, which can't hold a token, so each needs a token rule or a Graphite class. - bg-primary (navbar) - text-danger and text-muted (KPIs) - bg-success, bg-danger, bg-warning text-dark (badges) - btn-outline-light - Status badges (index.html:28-30): these show a state in a table cell.
