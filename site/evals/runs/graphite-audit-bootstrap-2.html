## Graphite UI audit: Clinic Rota Stack: static HTML, Bootstrap 5.3.8 from the CDN, plus one stylesheet (custom.css). No build, no Sass, no JS color config. Baseline: 16 findings, all in custom.css. index.html has no findings from the script, but it has the problems listed further down. I ran the audit on the two app files only; a run on the whole directory also picked up the skill templates under .claude/. ### Findings by rule (custom.css) | Rule | Count | Lines | |---|---|---| | color-literal | 6 | 2, 3, 7, 8, 10, 11 (#7c3aed three times, #e9d5ff, #6b7280, rgba(0,0,0,.15)) | | legacy-token | 3 | 2–4: --brand, --bs-primary, --bs-primary-rgb | | legacy-ref | 1 | 9: color: var(--brand) | | raw-radius | 2 | 8 (14px), 12 (18px) | | raw-font-size | 2 | 9 (34px), 10 (13px) | | raw-shadow | 1 | 7: navbar shadow | | important | 1 | 11: .btn-primary background | Worst file: custom.css with all 16. That's nearly every line of the file. ### Problems the script misses (index.html) - Dark mode: there's a data-bs-theme="light" attribute and a toggle script that flips it (index.html:2, and the #theme button with its script). Graphite tokens switch themes on their own, so the attribute, the button and the script would all go. - Bootstrap color utilities: bg-primary and navbar-dark on the nav, text-danger on the KPI, bg-success, bg-danger, bg-warning text-dark on the badges, and text-muted twice. These read the --bs-*-rgb triplets, so the bridge doesn't reach them. Each one needs a token rule or a Graphite class instead. - Purple brand that never fully applies: setting --bs-primary and --bs-primary-rgb on :root doesn't change .btn-primary. Bootstrap builds buttons, alerts and badges with a primary color fixed at build time, which is why line 11 needs !important. Even with it, hover, active and focus states stay Bootstrap blue. - Components that need porting: .btn-primary, .btn-secondary, .btn-outline-light, .alert-danger, .badge, .card.kpi, .table-striped, .modal-content, .form-select (its arrow is a hex SVG), .btn-close. - .kpi border: a 1px #e9d5ff border. Graphite uses box-shadow: var(--gr-shadow-border) with border: 0. - .kpi-value: font-weight: 700 plus a hardcoded 34px size. That's a display role, so it should use a --gr-text-* token. ### What can be deleted - All of :root in custom.css, once the brand is set through the Graphite brand settings (from brand.mjs "#7c3aed"). - The .btn-primary override on line 11. - The theme toggle button and its script. ### Not done - I made no edits and ran nothing past the audit: no brand.mjs, no contrast check, no browser check. - If you want the rework, the next step is the plan (brand settings, a map of the old tokens, a map of components to recipes) for you to approve.
